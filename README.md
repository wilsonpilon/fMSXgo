# fMSX Go Port (Experimental)

This repository contains an experimental Go port of the fMSX emulator. It is being developed with the sole purpose of providing a custom, lightweight debugging environment to assist in the creation of non-commercial MSX software projects. 

This is not intended to be a fully featured emulator for general gaming, but rather a targeted development tool to facilitate stepping through code and testing logic directly within a custom workflow.
